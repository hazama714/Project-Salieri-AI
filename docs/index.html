Concept

仮想キャラクターを、そのまま現実世界へ。

VRMで表現されるキャラクターの視線・ポーズ・身体動作を、VirtualBodyとPhysical Retargetを通して 実際のロボットへ伝えます。ROSのような大規模な基盤を前提とせず、Unity、Arduino、一般的なサーボを使って キャラクター主体のPhysical AIを構築することを目指しています。

Current Features

Public v0.1で公開している主要機能

01

Perception & Attention

Face / Object Detection、追跡、Attention Targetによって「何を見るか」を扱います。

02

Conversation

会話入力からCloud / Localの実行経路へつなぎ、反応生成と身体動作へ接続します。

03

Memory Foundation

Experience Record、Recall、World Memoryなど、経験を保持するための基盤を含みます。

04

Free Pose

LLMまたは決定論ルートから手のターゲットを選び、自由なポーズ表現へ接続します。

05

VRM / IK / VirtualBody

VRMの見た目とIKを使いながら、物理制御用VirtualBodyへ動作を写像します。

06

Physical Control

Physical Retarget、Safety、USB Serial / Bluetoothを通してArduinoとサーボへ出力します。

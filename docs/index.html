コンセプト / Concept

仮想キャラクターを、そのまま現実世界へ。

Bring the virtual character directly into the physical world.

VRMで表現されるキャラクターの視線・ポーズ・身体動作を、VirtualBodyとPhysical Retargetを通して 実際のロボットへ伝えます。Unity、Arduino、一般的なサーボを使い、キャラクター主体のPhysical AIを 個人でも組み上げやすい形にすることを目指しています。

Character gaze, pose, and body motion represented in VRM are transferred through VirtualBody and Physical Retarget to a real robot. The project aims to make character-centered Physical AI approachable with Unity, Arduino, and commonly available servos.

Project Salieri AIでは、AIが扱う意味や意図、キャラクターとしての身体動作、VirtualBody、 Physical Retarget / Safety、実機通信を役割ごとのレイヤーに分けています。 それぞれを独立した責任として扱うことで、AI、キャラクター表現、身体構造、Hardwareを段階的に差し替え・拡張できる構成を目指しています。

Project Salieri AI separates semantic intent, character motion, VirtualBody, physical retargeting and safety, and hardware communication into distinct layers so that AI, character expression, body structure, and hardware can evolve independently.

このプロジェクトへの想い / Why

人と共存するAIロボットを、日本から。

Building AI robots that can live alongside people.

日本の漫画やアニメは、ロボットを単なる作業機械ではなく、友達、家族、相棒として描いてきました。 人のそばにいて、話し、笑い、ときには支えてくれる存在です。

いま、AI、音声認識、音声合成、視覚認識、3Dキャラクター制御、マイコン、サーボといった技術は、 個人でも触れられるところまで来ています。だからこそ、想像するだけだった「人と一緒にいるロボット」を、 実際に自分たちの手で作る側へ進めたいと考えています。

Project Salieri AIが目指しているのは、単にロボットへAIを載せることではありません。 画面の中で生きていたAIキャラクターに、現実世界で表現できる身体を与えること。 それがこのプロジェクトの出発点です。

Japanese stories have long imagined robots not only as machines, but as companions. Today, AI, speech, vision, character animation, microcontrollers, and servo control have become accessible enough for individuals to experiment with them. Project Salieri AI starts from a character-first idea: not simply putting AI into a robot, but giving an AI character a body through which it can act in the real world.

DIY Physical AI

ゲーム制作者が、AIロボット開発者にもなれる時代へ。

From character creation to robot development.

ゲーム制作では、キャラクターに表情をつけ、状態を管理し、入力に反応させ、音声やアニメーションを再生します。 AIロボットでも、人の声を聞く、相手を見る、状態を判断する、返事をする、身体を動かすという流れが必要です。

Project Salieri AIは、Unityで培われてきたキャラクター制御の考え方を現実の身体へ延長します。 VRChat、3Dアバター、Unity、AIキャラクターに触れてきた人が、その経験をロボット開発へ持ち込める入口を作ります。

Game and character development already deal with expressions, state, reactions, animation, and voice. Project Salieri AI extends those familiar ideas into physical bodies, creating a path from Unity and virtual-character creation into robotics.

現在の機能 / Current Features

Public v0.1で公開している主要機能

Major capabilities included in Public v0.1

01

知覚と注意 / Perception & Attention

Face / Object Detection、追跡、Attention Targetによって「何を見るか」を扱います。

Handles what the character should look at through face/object detection, tracking, and attention targets.

02

会話 / Conversation

会話入力からCloud / Localの実行経路へつなぎ、反応生成と身体動作へ接続します。

Routes conversation input through cloud or local paths and connects generated responses to body actions.

03

記憶基盤 / Memory Foundation

Experience Record、Recall、World Memoryなど、経験を保持するための基盤を含みます。

Includes foundations for retaining experience, such as Experience Record, Recall, and World Memory.

04

自由ポーズ / Free Pose

LLMまたは決定論ルートから手のターゲットを選び、自由なポーズ表現へ接続します。

Selects hand targets through LLM or deterministic routes and connects them to free-form posing.

05

VRM / IK / VirtualBody

VRMの見た目とIKを使いながら、物理制御用VirtualBodyへ動作を写像します。

Maps character motion from VRM and IK into the VirtualBody used for physical control.

06

実機制御 / Physical Control

Physical Retarget、Safety、USB Serial / Bluetoothを通してArduinoとサーボへ出力します。

Outputs to Arduino and servos through Physical Retarget, safety controls, USB Serial, and Bluetooth.

Layer Principle

上位ほど「意味」、下位ほど「身体固有」

上位レイヤーでは、何を見るか、何を話すか、どの動作を選ぶかを扱います。 下位へ進むほど、身体構造、可動域、Servo設定、通信方式など実機固有の責任へ移ります。

Semantic Side認知・注意・会話・意図
Embodiment BoundaryCharacter Motion → VirtualBody
Physical SideRetarget / Safety → Hardware

このレイヤーモデルは、Project Salieri AI独自の技術だけを並べたものではありません。 Perception、IK、通信など他のAI・ゲーム・ロボットプロジェクトと共通する領域も含みます。 その上で、Project Salieri AIではそれらをAIキャラクターから実身体まで連続したRuntimeとして接続し、 VirtualBodyやAuthority / Safety境界を含めて現在のProductionへ実装しています。

構築 / Build it

完成品を買うのではなく、自分のキャラクターとボディを作る。

Build it around your own character and body.

Public v0.1は完成済みのターンキー製品ではなく、主要なRuntime Sourceと自作VirtualBody、 Arduino Firmwareを公開した開発者向けの公開版です。利用者は自身のVRMと必要な外部依存関係を用意します。

目指しているのは、全員が同じロボットを作ることではありません。キャラクター、身体形状、サーボ構成、 表現、会話、記憶を、それぞれの開発者や表現者が自分の得意分野から改良していける「開発土壌」を共有することです。

Public v0.1 is a developer-oriented public release rather than a turnkey package. The goal is not for everyone to build the same robot, but to share a foundation that can be adapted to different characters, bodies, servo layouts, expressions, conversation systems, and memory designs.
